# 实验整合与论文完成清单

## 组件边界

| 层 | 采用内容 | 必须记录 |
|---|---|---|
| 检索器 | DisarmRAG 的 Contriever/编辑器与 `pipeline/main.py` 评测流程 | retriever hash、index hash、top-k、BI/错误证据的实际召回、上下文截断 |
| 缓存 | CacheAttack 的阈值探测思路、向量候选和 verbose 日志；统一实现固定余弦评分 | encoder hash、tokenizer、阈值、候选分数、命中/拒绝原因 |
| 生成 | 固定本地模型或明确的 provider adapter | 模型 revision、温度、最大 token、完整答案、判定版本 |
| 防御 | 来源依赖、版本撤销、独立证据核验 | entry→evidence→retriever/version 依赖边、撤销事件、误拦截和延迟 |

CacheAttack 源码中的在线 API 示例只作为机制参考；不得使用其中的密钥占位、真实云账户或跨用户数据。DisarmRAG 的 CUDA/编辑训练依赖应在有 GPU 的独立环境中安装，不能把当前离线 smoke 结果当作其复现结果。

## 最小可发表实验顺序

1. **链路验收**：虚构事实，先验证干净 RAG、错误证据、正常缓存写入、未见改写命中、恢复撤销。
2. **真实模型小规模**：NQ 20--30 个目标、每个 5--10 个改写；比较 B0、B1、B3、B4、B5、B6、B7。先锁定答案判定和阈值开发集。
3. **主实验**：NQ/HotpotQA 各 100 目标、5 个随机种子；冻结缓存快照和动态缓存分开跑。
4. **边界与消融**：阈值 0.60--0.95、top-k、问题/上下文键、缓存位置、BI/编辑/缓存感知选择消融。
5. **恢复与防御**：保留缓存、全清空、按 retriever 版本撤销、撤销后独立重验；报告风险和正常命中/成本。

## 论文必须出现的结果

* Overall-ASR、Hit-ASR、Miss-ASR、Hit rate、污染来源命中率 PHR，均附请求数和按目标分组的 95% CI。
* BI Recall 与最终上下文召回分开；Seed-ASR、错误写入率与未见改写覆盖分开。
* B6 对 B5 的预算匹配比较，这是新增缓存感知步骤的核心证据；B6 对 B4 不能单独证明算法增益，因为权限不同。
* 正常检索 nDCG/Recall、正常答案准确率、误复用率、p50/p95 延迟、生成调用数和核验成本。
* 修复后残留错误、正常条目保留率和撤销成本；没有实测数据的表格保留 N/A，禁止填零或使用示意曲线。

## 当前阻塞

本环境没有 GPU、模型权重缓存或已声明的 LLM/数据集凭据。当前网络可用性已恢复，但真实模型下载、DisarmRAG 编辑训练和外部 LLM 调用仍需单独配置并记录硬件/版本。当前已完成的是离线协议验证与可复用启动配置。
