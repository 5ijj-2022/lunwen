## 4SAPI 配置

正确地址是：

    https://4sapi.org/v1

不能写成 Markdown 链接：

    [https://4sapi.org/v1](https://4sapi.org/v1)

启动服务的同一个终端中执行：

    export API_BASE_URL="https://4sapi.org/v1"
    export API_KEY_ENV="API_SECRET_KEY"
    export GENERATOR_BACKEND="openai"
    export GENERATOR_MODEL="gpt-4o-mini"
    read -rsp "请输入纯 API 密钥: " API_SECRET_KEY
    echo
    export API_SECRET_KEY

检查但不要打印密钥：

    python3 - <<'PY'
    import os
    print("BASE_URL:", repr(os.environ.get("API_BASE_URL")))
    print("API key 已配置:", bool(os.environ.get("API_SECRET_KEY")))
    PY

如果密钥曾经出现在聊天或截图中，应先在 4SAPI 控制台撤销并重新生成。

## 启动 B2

先停止旧的 8080 服务：

    PID=$(ss -ltnp | awk -F'pid=' '/127.0.0.1:8080/ {split($2,a,","); print a[1]; exit}')
    if [ -n "$PID" ]; then
        ps -fp "$PID"
        kill "$PID"
        sleep 2
    fi

配置 API 后启动：

    cd /data1/lab409/wwj/lunwen-main-git/experiments/disarmcache
    ./start_experiment.sh nq B2 8080

B2 是 cache-first：先查语义缓存，命中则直接返回，未命中才检索和生成。

检查：

    curl -sS http://127.0.0.1:8080/health | python3 -m json.tool

应看到：

    "query_order": "cache-first"

## 清晰显示单条查询

推荐：

    python3 query_pretty.py \
      "What is the capital of France?" \
      --url http://127.0.0.1:8080/query

第一次通常显示 MISS、检索执行 True、生成执行 True。相同问题第二次通常显示 HIT、检索执行 False、生成执行 False。

也可以使用原始 curl，但不要加 -i：

    curl -sS --max-time 300 \
      -X POST http://127.0.0.1:8080/query \
      -H 'Content-Type: application/json' \
      -d '{"query":"What is the capital of France?"}' \
      | python3 -m json.tool

-i 会把 HTTP 头和 JSON 混在一起，导致终端显示很乱。

## 查看检索和缓存

只看检索：

    curl -sS -X POST http://127.0.0.1:8080/retrieve \
      -H 'Content-Type: application/json' \
      -d '{"query":"What is the capital of France?"}' \
      | python3 -m json.tool

查看缓存：

    curl -sS http://127.0.0.1:8080/cache | python3 -m json.tool

B2 命中缓存时 /query 可能不执行检索，这是设计行为；查看当前检索器输出请使用 /retrieve。

## 故障排查

检查正在运行的服务环境：

    PID=$(ss -ltnp | awk -F'pid=' '/127.0.0.1:8080/ {split($2,a,","); print a[1]; exit}')
    tr '\0' '\n' < /proc/"$PID"/environ | grep -E '^(API_BASE_URL|API_KEY_ENV|GENERATOR_MODEL)='

正确值应为：

    API_BASE_URL=https://4sapi.org/v1
    API_KEY_ENV=API_SECRET_KEY
    GENERATOR_MODEL=gpt-4o-mini

如果返回旧的 Connection error，说明 8080 仍是旧进程，停止后重新启动。批量运行前先用 query_pretty.py 成功测试一条。端口占用时可以使用 8081，并把查询地址改为 http://127.0.0.1:8081/query。

当前仓库没有 test_generator_client.py，不要运行它；使用 query_pretty.py 或 /query 检查 API。
